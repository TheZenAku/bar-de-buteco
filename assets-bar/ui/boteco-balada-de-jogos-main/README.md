# Boteco Balada De Jogos

crie um conceito de UI para meu jogo de navegador, o jogo é sobre estar em um bar, beber se divertir, conversar, resenhar, jogar, então a interface tem que ser algo "divertido" mas não infantilizado, algo que passe a ideia de um jogo único e sem noção. A paleta de cores é a imagem em anexo, se inspire nisso, pense em cerveja, vodka, sujeira, mijo, vômito, carteado, poker, black jack, bar de boteco, bilhar, brasil.
