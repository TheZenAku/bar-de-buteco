# Shuffle And Shimmy Social

eu preciso de uma interface gráfica para meu jogo social de bar, eu não tenho uma ideia fixa para o design ainda, mas tem que puxar pra uma temática mais "divertida", eu quero uma interface que seja versátil acima de tudo, que eu possa mover as coisas, possa recolher as coisas pra poder ajustar da maneira que eu quiser, quero letras fáceis de entender também e uma fonte que seja de acordo com a proposta, no jogo vai ter bebedeira, dança, risada, interações com vários itens do cenário, uma coisa bem completa mesmo, quero que o usuário tenha liberdade ao jogar que ele se sinta acolhido de certa forma, mas a interface tem que lembrar que aquele jogo ainda é um jogo de bar, eu também quero que no caso de você for colocar ícones que utilize algum pacote free da internet e evite usar emojis
